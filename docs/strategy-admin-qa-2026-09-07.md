# Стратегия и админка: доработка и проверка

Изменения этого прохода локальные; автоматический push/deploy не выполнялся.

## Что изменено

- Стратегия: поля в две колонки, сопровождение в раскрывающихся секциях, закреплённая панель сохранения, индикатор изменений, блокировка полей на время сохранения.
- Расчёт изменений учитывает реактивность вложенных bindings Svelte: изменение trailing/trading/features активирует сохранение.
- Админка: один компонент для раздела «Ещё» и `/admin`, управление сверху, компактные строки через props InfoRow вместо вложенных слотов/карточек.
- Показываются семь реальных параметров V3; базовые параметры и полная статистика доступны в раскрывающихся блоках.
- Ошибка отдельного API не скрывает успешно загруженные данные. Недоступные значения не подменяются нулями.
- Сброс требует подтверждения и повторно читает статистику, поскольку ответ reset содержит снимок до очистки.
- Общая проверка видимости админки использует авторизованную сессию и Telegram ID; она не заменяет серверную авторизацию.
- На обзоре сокращены подпись статуса и размер карточек, переключатель PnL расположен в одну строку.

## Проверено

Локальный fixture API, без настоящих ключей и обращения к бирже:

1. Загружаются mode=0, PascalCase runtime и Counts; в интерфейсе видны режим, параметры V3 и 120 отказов.
2. Запуск при выключенном тюне показывает объяснение, без ложного успеха.
3. Переключение в safe и запуск: fixture меняет балл 7 → 6, интерфейс обновляет параметр и дату тюна.
4. Подтверждённый сброс: показано 0 вместо старого снимка 120.
5. Ответ 503: явная ошибка и повторная загрузка после восстановления API.
6. Раскрытие BE, изменение 0.6 → 0.8, сохранение; значение 0.8 осталось после ухода и возврата на страницу.
7. Фактический DOM viewport 320 CSS px: scrollWidth=320, выступающих кнопок/полей/карточек нет.

Автоматические проверки: 6 node-тестов; svelte-check 0 ошибок/0 предупреждений; ESLint 0 ошибок (32 существующих предупреждения); production build; Go-тесты API controller, runner service, strategy service.

Реальный запуск тюна, изменение рабочих параметров, сброс рабочей статистики и торговые операции не выполнялись. Проверка на сервере после деплоя требует авторизованного Telegram Mini App.
